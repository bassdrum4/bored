# Incoming SP skins

These are Vettel's SP skin drawings for Poké Gacha. They are upscaled pixel art, so recover the
1x size the same way as the other gacha art before using them. This folder is only for handing
the files over: move them into the game's skin folder and leave this branch unmerged.

A skin is owned per evolution line and shows on the form it was drawn for. A set is one skin
that covers every form listed with it.
