    How to play

    • Answer the category before the puffer explodes on you.
    • Pass it on and the next diver inherits whatever fuse is left, with the room's MIN. TURN as the floor.
    • Rarer answers fill your meter. Six hundred points buys an extra heart.
    • You cannot reuse an answer for the current category.
    • You start with the hearts the host set and can hold five. Lose them all and you watch. Last diver floating wins.

    Rated rooms move a rating that starts at 1200. Quick play changes nothing.

    Room rules

    The host sets these while the room is still asleep.

    METER TARGET
    600

    600 points buys an extra heart.

    • An answer already used for this category is refused.
    • Lose every heart and you watch. Last diver floating wins.
